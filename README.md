> TerraScore turns localized weather, soil, crop and location data into a dynamic, explainable **0–1000 agricultural climate-risk score** for lenders, insurers, agri-platforms and development institutions.

> ⚠️ **TerraScore is a prototype decision-support system using simulated data. It is not a credit score, insurance underwriting decision, or financial advice.**
> Data source everywhere in the app: *Simulated / synthetic demo data*.

LINK FOR THE WEBSITE - https://terra-score.vercel.app/

FASTAPI was used here in backend
ML model works on on a dummy dataset to predict simulated score
